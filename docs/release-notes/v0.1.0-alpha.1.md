# 安卓姐姐 v0.1.0-alpha.1

首个公开开发预览版：把 Android 真机上的桌面应用通过 ADB 与 scrcpy 带到 Mac，并提供 Android 14+ Fusion 虚拟显示。

## 包含

- USB / Wi-Fi ADB 设备发现与授权状态
- Android 设备信息与可启动应用列表
- 普通投屏
- Android 14+ Fusion 模式
- 本地 ADB / scrcpy 路径设置

## 下载前请注意

- 产物：macOS Apple Silicon
- 最低系统：macOS 15
- 依赖：ADB、scrcpy 4.x
- 签名：ad-hoc，仅用于开发预览
- 公证：未完成
- 真机范围：一台 HONOR Android 14

如果你要求 Developer ID 签名、公证或广泛机型兼容，请暂时不要把这个预览版用于关键日常工作。
